About this portfolio

This portfolio covers both the programming concepts K-12 students need to know in a block-based language and the teaching approaches that help beginners learn them. Lessons are built step by step with low cognitive load, instead of simply telling a learner to "go write a program."

This site collects my work: teaching videos, lesson materials, shared programming projects, and my reflections on pedagogy and equity.

Core programming concepts

The core concepts I teach to beginners.

Sequences

Instructions run one after another, in order.

Iteration

Repeating steps, including repeating while a condition holds.

Selection (ifs)

Choosing which path to follow based on a condition.

Variables

Named values that hold and change over time.

Events

Code that runs in response to something happening, like a click or key press.

Abstraction, methods, parameters

Naming a set of steps so it can be reused with different inputs.

Ordered collections of items.

Pedagogy & equity

Each topic below will get a short reflection or artifact as I work through it.

  • Pair / buddy programming: two learners sharing one task and taking turns in different roles.
  • Peer instruction: learners test their understanding by explaining ideas to each other.
  • Culturally relevant teaching: connecting examples to learners' lives and contexts.
  • State of K-12 CS education and standards: what is taught, and what is missing.
  • Equitable lab classrooms: structures that give every learner access.
  • Interdisciplinary standards alignment: computing connected to other subjects.
