About this portfolio

This portfolio covers both the programming concepts K-12 students need to know in a block-based language and the teaching approaches that help beginners learn them. Lessons are built step by step with low cognitive load, instead of simply telling a learner to "go write a program."

This site collects my work: teaching videos, lesson materials, and shared programming projects.

  • Scaffolded lessons for beginners
  • Recorded teaching and explanation videos
  • Lesson plans and shared block-based projects

Repeats

A breakdancer sprite shows off its moves, using repeat loops to slide, spin, and shrink instead of writing the same blocks over and over.

Repeat Animal Parade

A dog, kangaroo, grasshopper, and bee each join the parade when their key is pressed, using a repeat loop to step forward again and again before switching costumes.

Nested Repeats

Putting one repeat loop inside another, so a whole pattern of repeated steps can itself be repeated, building bigger results from fewer blocks.

Watch the video

Events

How event blocks like "when green flag clicked" or "when key pressed" start a script, so a program reacts to what the user does instead of running all at once.

Watch the video

Variables

A sprite uses two variables, num_sides and side_length, to draw a triangle, square, and pentagon. The same repeat loop draws each shape, and changing num_sides by 1 makes it draw the next one.
